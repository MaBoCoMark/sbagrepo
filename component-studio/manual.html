Community Component System

The Rocket League Tactical Overlay features a high-performance 120Hz declarative component engine. Community developers can build custom HUD components simply by providing a Single File Component (SFC) in pure HTML.

💡 Zero Build Step: No npm install, no TypeScript compile, and no runtime JS boilerplate needed. The overlay dynamically extracts the manifest, DOM template, and CSS at runtime, binding telemetry updates at sub-millisecond speeds.

2. Single File Component (.html) Anatomy

Every component file must contain exactly three standard blocks:

  • <script type="application/json" id="component-manifest">: Declares metadata, telemetry bindings, and customizable property controls.
  • <template id="component-template">: The inner HTML template of the component.
  • <style>: Scoped CSS for the component, responsive via Container Queries (cqw, cqh).
Component SFC Skeleton 
<!-- my-component.html -->
<script type="application/json" id="component-manifest">
{
  "id": "element-my-text",
  "displayName": "My Custom Value",
  "tier": "element",
  "category": "player",
  "isProportional": false,
  "supportsAlignment": true,
  "defaultWidthVw": 6,
  "defaultHeightVw": 3.5,
  "baseWidthPx": 96,
  "baseHeightPx": 56,
  "customProperties": [
    { "key": "textColor", "label": "Text Color", "type": "color", "default": "#ffffff" },
    { "key": "strokeWidth", "label": "Stroke Width", "type": "number", "min": 0, "max": 10, "unit": "px", "default": 0 }
  ]
}
</script>

<template id="component-template">
  <div class="el-my-text-box align-right dyn-text-box">
    <span class="dyn-val">100</span>
  </div>
</template>

<style>
  .el-my-text-box {
    width: 100%;
    height: 100%;
    display: flex;
    align-items: center;
    container-type: size;
  }
  .el-my-text-box .dyn-val {
    font-weight: 800;
    font-size: calc(min(70cqh, 45cqw));
  }
</style>

3. Component Manifest Specification

The manifest is a JSON object located inside the <script id="component-manifest"> tag:

Field Type Default Description
id string Required Unique component identifier (e.g., element-boost-text).
displayName string Required Human-readable name displayed in Configurator & Catalog.
tier "element" | "widget" | "panel" "element" Component hierarchy tier.
• element: Atomic single-metric item.
• widget: Multi-metric combo.
• panel: Full HUD board.
category "player" | "global" "global" Scope of telemetry data.
• player: Supports target player switching (P1, P2, P3).
• global: Match scores, time, overtime, ball speed.
isProportional boolean true Whether 8-point drag resizer locks aspect ratio by default.
supportsSpeedUnit boolean false Enables km/h vs uu/s conversion selector in Configurator.
supportsAlignment boolean false Enables Left / Center / Right text alignment controls.
defaultWidthVw number 8 Initial default width in screen width percent (vw).
defaultHeightVw number 4.0 Initial default height in screen width percent (vw).
customProperties CustomPropertyDef[] [] Array of tunable schema properties for automatic UI control generation.

4. Live Telemetry Data Dictionary (120Hz Buffer)

The overlay synchronizes real-time state from Rocket League WebSocket. Your component can bind to any of the following fields:

Player Telemetry (Available per Target Player: P1, P2, P3)

Variable Key Type Range / Values Description
boost (p1Boost) number 0 ~ 100 Current boost amount.
speed (p1Speed) number 0 ~ 2300 (uu/s) Car linear velocity in Unreal Units per second.
name (p1Name) string e.g. "steamuser" Player username or gamertag.
bSupersonic (p1Supersonic) boolean true / false True when car is supersonic speed (>= 2200 uu/s).
bBoosting (p1Boosting) boolean true / false True when player is actively firing boost.
bOnGround (p1OnGround) boolean true / false True when all 4 wheels touch pitch ground.
bOnWall (p1OnWall) boolean true / false True when car is driving on stadium wall or ceiling.
bPowersliding (p1Powersliding) boolean true / false True when handbrake / powerslide is engaged.
bDemolished (p1Demolished) boolean true / false True when player has been demolished / respawning.
bHasCar (p1HasCar) boolean true / false True when car vehicle actor exists in match.

Global Match Telemetry

Variable Key Type Range / Values Description
timeSeconds number 0 ~ 300+ Match time remaining in seconds (e.g. 270 -> "4:30").
bOvertime boolean true / false True when game enters Sudden Death Overtime (+0:00).
scoreDiff number -99 ~ +99 My Team Score minus Opponent Team Score (+2, 0, -1).
myScore / oppScore number 0 ~ 99 Match scoreboard points for both teams.
ballSpeed number 0 ~ 200 (km/h) Current velocity of the ball.
ballTeamNum number 0 (Blue) / 1 (Orange) Team number of the last player to touch the ball.
myPrimaryColor hex string e.g. "#1873FF" Team primary body color in hex.
oppPrimaryColor hex string e.g. "#C26418" Opponent team primary body color in hex.

5. Custom Properties Schema Reference

Declare controls inside customProperties array in the manifest. The Configurator and Component Studio will automatically generate UI controls for users to customize them:

Property Type Required Fields Optional Fields Generated UI Widget
color key, label, type, default - Color Picker with Alpha & RGBA text sync.
number key, label, type, default min, max, step, unit Interactive Range Slider + value badge.
boolean key, label, type, default - Toggle Checkbox.
select key, label, type, options, default - Dropdown Selection menu.
string key, label, type, default - Text Input field.

6. CSS, Container Queries & Typography Guidelines

Global Monospace Font: Mona Sans Mono (GHMonoR)

The overlay enforces a high-legibility monospace font GHMonoR (defined in src/styles/main.css). This guarantees that rapidly changing digits (such as 100 -> 99 -> 0) will never cause horizontal layout shifting or jitter.

Outer Text Stroke (Clean Outlines)

To make text readable against any arena background without clipping the inner letter glyphs, always combine -webkit-text-stroke with paint-order: stroke fill:

CSS Outer Stroke Technique
.dyn-val {
  -webkit-text-stroke: 4px #000000;
  paint-order: stroke fill; /* Paints the stroke behind the fill! */
}

Container Queries (cqw, cqh)

All components should set container-type: size; on their root box. Use calc(min(70cqh, 45cqw)) for font sizes so the text scales fluidly when resized by the 8-point dragger:

Fluid Scaling Example
.my-box {
  width: 100%;
  height: 100%;
  container-type: size;
}
.my-box .dyn-val {
  font-size: calc(min(75cqh, 40cqw));
}
